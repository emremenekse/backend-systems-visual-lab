# Guided lesson

Vite + React lesson for predicting the outcome, running the live race,
understanding each side effect, and rehearsing interview answers. The raw event
trace is available only as optional technical depth.

```bash
npm install
npm run dev
```

The development server proxies `/api` to `http://localhost:8080`.

The embedded video is generated by the sibling `video` project:

```bash
npm --prefix ../video run publish:visual
```
